# Publication Blockers

## Critical

1. Official dataset archive lineage remains conflicting/incomplete.
2. The reliability-aware contribution has no controlled comparative evidence.
3. No fair publication-grade simple and neural baseline programme exists.
4. No multi-seed evidence exists.
5. No controlled ablation programme has executed.
6. No paired confidence intervals, effect sizes, or corrected statistical tests
   exist.
7. Protected final evaluation is not authorized and must remain untouched.

## High

1. The preserved model underfits; validation ROC-AUC is approximately 0.60.
2. Historical training provenance lacks the exact dirty source patch, complete
   configuration, command transcript, and full environment lock.
3. Required detector calibration is absent, blocking calibrated inference.
4. The active environment contains dependency conflicts.
5. No complete evidence-bound IEEE manuscript package exists.

## Missing implementation versus missing evidence

- Missing evidence: baselines, ablations, multiseed runs, paired statistics,
  protected test result, contribution verdict, final figures/tables.
- Incomplete implementation: frozen experiment configuration and registry,
  test-access guard, baseline/ablation validation, complete prediction
  provenance, calibration restoration.
- External/scientific blocker: authoritative dataset acquisition provenance.

Phase 2 can define a defensible validation-only programme without resolving the
external archive issue, but no final dataset-identity claim or submission-ready
classification is permitted until that limitation is resolved or explicitly
accepted and disclosed.
