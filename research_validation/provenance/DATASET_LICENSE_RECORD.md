# Dataset License Record

The repository identifies the dataset as MIMII and records the official Zenodo
release as public 1.0 with CC BY-SA 4.0: <https://zenodo.org/records/3384388>.
This establishes the terms of the cited release, not cryptographic identity of
the local extracted directory. The local acquisition receipt, original archive
hash, and authoritative per-file checksum set are unavailable. Local license
identity is therefore **PARTIALLY VERIFIED** and remains a PMPS-01 blocker.
