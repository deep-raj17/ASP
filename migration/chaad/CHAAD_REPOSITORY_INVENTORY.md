# CHAAD Repository Inventory

Inventory time: 2026-07-24  
Scope: pre-adapter CHAAD content in the shared repository

The read-only inventory contains 393 files totaling 26,734,217,024 bytes after
excluding `.git`, the local virtual environment, caches, private `.ros` state,
and newly generated adapter/migration files. It includes 104 checkpoint files,
63 artifact files, 93 documentation files, 16 scripts, seven tests, source
modules, configuration, reports, metadata, logs, and deployment assets.

`CHAAD_FILE_INVENTORY.csv` is the machine-readable inventory. SHA-256 was
computed from current bytes for files up to 50 MiB. Checkpoint hashes were
joined from the verified PMPS-01 checkpoint registry. Other large files are
explicitly `NOT_REHASHED_LARGE_FILE`; they are not silently treated as
verified.

No manuscript source package or submission release was found. Existing
publication-named reports are readiness assessments, not proof of publication.
The local virtual environment is environment material but is excluded from the
file-level table because `environment_full.json` and
`requirements_frozen.txt` are the portable evidence records.
