# CHAAD ROS Adapter

This adapter maps the existing CHAAD repository into ROS without modifying
scientific artifacts. Configure private paths by copying
`paths.local.yaml.example` to the ignored `paths.local.yaml`.

The imported PMPS 1.0.0 instance is honestly `BLOCKED` at PMPS-01. This is not
a model failure and not a publication-readiness claim. Required full-corpus
integrity and local-to-authoritative dataset identity evidence are missing.

Re-import is append-only and idempotent. Historical invalid and corrected
validation exports remain distinct records.
